Pilih jenis latihan.

Latihan Abstrak

Tiap menu berisi 30 kata acak. Selesaikan berurutan atau pilih sendiri.

Latihan Jari

Tiap menu berisi 30 kata acak dari tombol satu jari di kedua tangan sekaligus.

Kata Acak

Kata acak dari file kategori yang Anda unggah. Jumlah kata per drill mengikuti isi file.

Satu drill berisi semua kata di file kategori sekali putaran (urutan acak), jadi batas kata mengikuti jumlah kata di file. Pilih “Semua kategori” untuk menggabungkan seluruh file. Tekan Esc untuk berhenti lebih awal.

Belum ada kategori. Unggah file .txt dengan format: judul di baris pertama (opsional, contoh T01. DIRI & KELUARGA (L1-L2)), lalu sub-kategori di dalam kurung siku [Nama] diikuti kata-kata yang dipisah koma. Tanpa judul pun boleh, termasuk satu kata per baris. Bisa memilih banyak file sekaligus.

Teks Unggahan

Cerita atau simulasi percakapan dari AI (.txt), diketik utuh dari awal sampai akhir.

Belum ada teks. Unggah file .txt berisi cerita atau percakapan. Karakter yang tidak ada di keyboard (emoji, tanda kutip lengkung, tanda pisah panjang, format markdown) otomatis dibersihkan atau diganti. Bisa memilih banyak file sekaligus.
